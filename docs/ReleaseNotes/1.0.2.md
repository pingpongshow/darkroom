# DarkRoom 1.0.2

**Library**
- RAW badge on RAW photos in the grid
- Select several photos with ⌘-click, or a range with ⇧-click
- Deleting a photo from the single-photo view and going Back returns to the same place in the grid
- The map opens much faster, with photos grouped into pins for the area in view
- Set Date & Time: pick the date on a calendar or type it, with the time zone; the old "Shift by" is gone

**Editing**
- RAW photos open in the editor looking the same as in the library, without an automatic change in colour or brightness
- Cropping or rotating a RAW photo now saves an edited version stacked on the original
- Clicking Save while the crop box is open keeps the crop
- After saving, the edited photo shows straight away instead of a "not found" error
- Fixed the editor sometimes showing nothing after reopening a photo

**Connection**
- If macOS's Local Network setting blocks your Immich server, DarkRoom explains how to allow it

# DarkRoom 0.1.0

First release: a native Mac client for Immich.

- Multi-user sign-in with a DarkRoom PIN or Touch ID, quick switching and locking
- Fast timeline, loupe, search, Explore, People, Places, map, albums, sharing, memories
- Organising: ratings, favourites, pick/reject flags, tags, dates, locations, stacks, archive, locked folder, trash with undo
- Develop: RAW processing, tone, colour, curves, colour grading, detail, effects, lens and transform corrections, masks, retouch, presets and LUTs; non-destructive versions stacked on the original
- HDR and panorama merge, crop and rotate, lossless video rotation, Make Still
- Edit in companion apps (Photoshop, Pixelmator Pro, darktable and more)
- Import from any disk straight to Immich, with duplicate detection and Live Photo / RAW+JPEG pairing
- Export with watermarks and presets, Quick Look, Shortcuts actions, menu bar status
- Read-only mode for a first look at an existing library
